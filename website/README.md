# Stay Awake — website

Static marketing site for the Stay Awake tray widget. No build step: open
`index.html` in a browser or serve the folder with any static file server:

```sh
cd website
python3 -m http.server 8080
# open http://localhost:8080/
```

## Contents

- `index.html` — fully SEO-optimized landing page (Open Graph, Twitter card,
  SoftwareApplication + FAQPage JSON-LD, semantic HTML).
- `assets/logo-64.png` — 64×64 product logo (mint power glyph on a dark tile,
  matching the app UI). `assets/logo-512.png` is the high-res master.
- `assets/favicon.{ico,svg}` + `favicon-16x16/32x32.png`,
  `apple-touch-icon.png`, `android-chrome-192x192/512x512.png` — favicons.
- `assets/og-image.png` (1200×630) — social preview image.
- `assets/banner.png` (1920×480) — wide bonus banner for GitHub social preview.
- `assets/screenshot-{awake,sleep}.png` — real app screenshots.
- `site.webmanifest`, `robots.txt`, `sitemap.xml` — SEO / PWA metadata.

## Before deploying

`index.html`, `robots.txt` and `sitemap.xml` assume the site lives at
`https://mihastele.github.io/cross-platform-sleep-prevention-button/website/`.
If you deploy the folder contents as the site root instead, drop the
`/website` path segment from those absolute URLs.

Assets are generated by `scripts/render_website_assets.py` (Pillow + system
fonts). Re-run it from the repo root after changing the logo design:

```sh
python3 scripts/render_website_assets.py
```
